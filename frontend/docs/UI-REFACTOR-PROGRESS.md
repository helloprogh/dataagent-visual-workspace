# UI 持续重构进度

目标：全部生成式 UI 统一 A2UI，AG-UI 保持运行及审批真源；独立迭代验证后提交并推送。

## 迭代路线

1. 恢复浏览器测试、依赖锁定、统一 CI，修复测试暴露的功能退化。
2. 状态正确性：模型隔离与失败回滚、分页竞争、审批 schema、A2UI busy、预览限流。
3. Conversation 展示层：滚动、面板、输入区、展示模型和预览数据源。
4. A2UI 统一：Catalog 契约、业务卡片、动作路由、历史兼容及回放验证。
5. 会话和产品体验：重命名、搜索、警告、主题字体、上传状态。
6. 性能基线及扩展：资源加载、长会话、Agent Runs 和文件预览能力按后端契约推进。

## 迭代 2：模型与分页隔离（已提交推送：33277bc，远端 CI 成功）

- 模型切换失败恢复旧选择；会话切换或卸载后忽略旧模型请求；加载期间切换会话也会加载对应模型。
- 模型初始化从当前有效目录中解析记忆值和默认值。
- 历史分页绑定会话代次及 client，旧分页结果不覆盖新会话消息、cursor、loading 或错误状态。
- 切换会话后旧 Run 的 finally/catch 不覆盖新会话运行及中断恢复状态。
- 新增浏览器用例：模型切换失败回滚、模型加载期间切换会话、旧会话分页晚到后新会话仍可分页。
- 验证：Chromium 19/19 通过（21.9 秒）；`npm run check` 的 120 项测试、类型检查和生产构建通过。
- 下一轮：A2UI 动作 busy、审批 schema 与日期时间、文件预览字节限制；随后继续展示层与统一协议迁移。

## 迭代 3：交互和输入边界（已提交推送：7c794a2，远端 CI 成功）

- A2UI 动作按钮使用真实运行/待审批状态，不再依赖固定六秒计时器；补充立即重复点击保护。
- 审批表单与提交入口共用显式 schema 子集校验；不支持的结构提示并阻止提交，日期时间保留时区。
- 修复多中断快捷按钮仅提交单条答案的问题，统一收集全部答案后提交。
- 普通及 ZIP 文本预览按 UTF-8 字节限制为 1 MiB，支持无 Content-Length 响应，取消多余读取并清除跨文件状态。
- 增加支持范围文档 `APPROVAL-AND-PREVIEW-CONTRACT.md` 和输入边界单元/浏览器回归。
- 验证：`npm run check` 的 127 项测试、类型检查和生产构建通过；Chromium 26/26 通过（28.2 秒）。浏览器使用模拟 API/SSE，不代表真实 OpenCode 联调；既有构建警告仍保留。
- 下一轮继续 Conversation 展示层拆分，随后推进 A2UI 单一渲染入口及历史兼容。

## 迭代 4：会话视口职责拆分（验证完成）

- 提取 `useConversationScroll`，集中管理流式跟随、跳至最新、触顶分页和视口位置恢复，不复制运行时状态。
- 手动加载旧消息也使用分页高度补偿，避免与自动触顶重复请求。
- 会话切换或卸载使旧分页补偿和排队滚动失效，避免移动另一会话的复用容器。
- 新增 5 项组合函数测试；加强浏览器竞争测试，验证旧分页返回后新会话阅读位置保持不变。
- 验证：132 项单元测试、类型检查和生产构建通过；Chromium 26/26 通过（28.9 秒）。既有 CSS/分包警告保留，真实服务联调仍未覆盖。
- 下一轮：展示派生与面板/输入职责继续拆分，再推进 A2UI 单一渲染入口。

## 验证规则

每轮执行对应行为测试、类型检查、构建及差异检查。协议或公共运行时变化执行 Adapter 回归；记录实际测试环境，不将 mock 浏览器测试称为真实 OpenCode 联调。

Windows 本地示例：

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
$env:NO_PROXY = '127.0.0.1,localhost'
npm run test:e2e
npm run check
```

每轮只暂存明确属于本迭代的文件。推送前核对暂存差异，推送后验证远端提交。
