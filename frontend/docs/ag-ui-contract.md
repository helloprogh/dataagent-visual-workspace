# Standard AG-UI Contract

The frontend connects directly to an AG-UI compatible backend via `@ag-ui/client` `HttpAgent`.

There is no CopilotRuntime and no OpenCode session bootstrap in the browser.

## RunAgentInput

No custom top-level properties are added:

```json
{
  "threadId": "thread-...",
  "runId": "...",
  "messages": [],
  "state": {},
  "tools": [],
  "context": [],
  "forwardedProps": {}
}
```

`threadId` is generated by the conversation layer and is stable for the lifetime of a conversation.

## Conversation persistence

Conversation metadata, messages, and state are persisted through a replaceable `ConversationRepository`. The demo implementation uses browser localStorage and can later be replaced by a REST-backed repository without changing the chat component.
